# AIGC 标注项目管理工具

这是适合在 Windows 电脑上运行的局域网共享版本。同一 Wi-Fi 下的电脑通过浏览器访问同一服务，数据统一保存在服务器电脑的 `data/store.json` 中。

## 在服务器电脑上启动

1. 安装 Node.js 18 或更高版本。
2. 首次使用时，以管理员身份运行 PowerShell，然后执行。该规则只允许本地子网访问 8088 端口：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\设置防火墙.ps1
   ```

3. 双击 `启动局域网服务.cmd`，并保持窗口运行。
4. 启动窗口会显示局域网网址，例如 `http://10.0.12.255:8088/`。
5. 首次启动后，在服务器电脑打开 `http://127.0.0.1:8088/`，设置管理员密码。首次设置只允许在服务器本机完成。

如需长期使用，可双击 `安装自动启动.cmd`。它会创建当前 Windows 用户的登录启动任务；服务异常退出时，守护脚本会在 3 秒后重新启动。

## 其他电脑访问

让其他电脑连接同一个 Wi-Fi，在浏览器中打开启动窗口显示的局域网网址。页面顶部显示“已同步 · 团队共享”即表示连接成功。

## 权限

- 项目、批次、单价、人员和职位权限由服务器端管理员验证保护。
- 普通用户在浏览器里选择“负责人”不会自动获得管理员权限。
- 只有持有管理员密码并登录的人才能修改权限；密码以加盐哈希保存在服务器电脑的 `data/auth.json`，不会下发到浏览器。
- 首次管理员设置只能从服务器电脑的回环地址完成。

## 并发同步

- 不同记录可由多人同时添加或修改，服务器按记录合并。
- 两人同时修改同一条记录时，服务器拒绝后提交的冲突改动并返回最新内容，页面会明确提示重新操作，不会静默覆盖先保存的数据。
- 一台电脑保存后，服务器会立即通知其他已打开的页面并刷新数据；同时每 15 秒检查一次，作为断线重连后的补偿。
- 页面刷新数据时会保留正在填写、尚未提交的表单内容。

## 多项目管理

- 人员按项目加入，同一个人可以参加多个项目，并在不同项目分别担任负责人、标注或质检。
- 旧人员不会自动加入新项目；必须由管理员在当前项目中明确加入，避免人员被混到所有项目。
- 管理员可在“全部人员归属”中为每个人勾选一个或多个项目，并为每个项目单独设置职位。
- 批次、人效、质检、出勤和报表都跟随页面顶部的“当前项目”分别显示。
- 每个人的标注日目标和质检日目标也按项目单独保存。
- 新建项目会自动切换到新项目，并保留人员表单中已经填写的姓名、团队和职位；新增人员只清空人员表单。

## 出勤统计

- 应出勤天数只计算项目开始日至今天；项目有结束日期时，不超过结束日期。
- 未来日期可以提前报备，但到达对应日期后才计入实际出勤，出勤率不会超过 100%。
- 出勤按“人员 + 日期”去重，未设置的已过日期计入“缺勤/未填”，请假单独统计。
- 新加入项目的人员从加入日期开始计算应出勤天数；管理员可补录和修正过去日期。

## 数据与备份

- 所有电脑共享的数据保存在服务器电脑的 `data/store.json`。
- 管理员密码配置保存在 `data/auth.json`；备份或迁移服务器时应与数据文件一起保管。
- 备份时复制这个文件即可。
- 不要同时启动多个服务实例写入同一个数据文件。
- GitHub Pages 和双击 HTML 的旧入口会自动跳转到 `http://10.0.12.255:8088/`，不再创建独立的浏览器本机数据。
