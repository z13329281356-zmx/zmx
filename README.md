# AIGC 标注项目管理工具

这是适合在 Windows 电脑上运行的局域网共享版本。同一 Wi-Fi 下的电脑通过浏览器访问同一服务，数据统一保存在服务器电脑的 `data/store.json` 中。

## 在服务器电脑上启动

1. 安装 Node.js 18 或更高版本。
2. 首次使用时，以管理员身份运行 PowerShell，然后执行。该规则只允许本地子网访问 8088 端口：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\设置防火墙.ps1
   ```

3. 双击 `启动局域网服务.cmd`，并保持窗口运行。
4. 启动窗口会显示局域网网址，例如 `http://10.0.12.255:8088/`。

## 其他电脑访问

让其他电脑连接同一个 Wi-Fi，在浏览器中打开启动窗口显示的局域网网址。页面顶部显示“已同步 · 团队共享”即表示连接成功。

## 数据与备份

- 所有电脑共享的数据保存在服务器电脑的 `data/store.json`。
- 备份时复制这个文件即可。
- 不要同时启动多个服务实例写入同一个数据文件。
- GitHub Pages 版本仍可访问，但它使用各浏览器的本机存储，不参与局域网同步。
